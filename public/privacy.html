Privacy Policy

n8n-project · Last updated 3 October 2026

n8n-project is a private automation tool built and run by Jessie Hinahon for her own work. It is not offered to the public. It signs in only to Google accounts that Jessie owns, and only she can connect an account to it.

What it accesses

  • Google Drive (drive.metadata.readonly): file names, folders and change dates in chosen folders, to report what changed. It cannot open, edit or delete files.
  • Google Sheets (spreadsheets.readonly): reads a task tracker to send task reminders. It cannot edit any sheet.
  • Gmail (gmail.readonly, gmail.compose): reads recent mail to build a daily summary, and saves reply drafts for Jessie to review and send herself.
  • Google Calendar (calendar.events): reads upcoming events for reminders and checks meeting invitations.

How the data is used

Data is used only to produce Jessie's own reports, reminders and drafts. Summaries are posted to private Discord and Slack channels that she controls. Email text may be processed by an AI model (Anthropic Claude) to write the daily summary and draft replies. Links are removed before it is sent.

What it does not do

  • It does not sell, rent or share Google user data with anyone.
  • It does not use Google user data for advertising.
  • It does not transfer Google user data except as described above to provide these features.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Storage and removal

Sign-in tokens and run history are stored encrypted on Jessie's own machine and are not shared. Access can be removed at any time from Google Account → Third-party connections.
